## Addendum 5 — ADR-045-ANCHOR-SET-1: anchor_path reactive write discipline fix

**Task:** Fix ADR-045 Rule R1 violation in `app/handlers/home_theater.py`.

### Violation

`anchor_path.set(str(out_path))` was called inside `@render.ui dynamic_tabs()` (line 655).
Writes to reactive values inside renders cause illegal Shiny client/server state transitions.

### Fix

- Removed `anchor_path.set()` from `dynamic_tabs()` render.
- Added `@reactive.Effect _sync_anchor_path()` immediately after `_track_tier_toggle()`.
  Reacts to `active_collection_id()`. Checks `out_path.exists()` and writes with idempotent guard:
  `if anchor_path.get() != new_val: anchor_path.set(new_val)`.
