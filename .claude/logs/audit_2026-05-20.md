### Why this approach

The edit machinery (`_render_action_form` + `_bp_apply_node_handler`) already handles all 8 widget types and writes the selected node by index. Unification therefore needed no new form code — add just creates+selects a stub and reuses the verified edit path. Minimal surface, no duplication.
