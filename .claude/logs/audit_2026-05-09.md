## Decisions Made

### Execution model: local over cloud (ADR-080)

**Decision:** All audit scripts run locally via systemd user timers, not Claude Code cloud `/schedule` Routines.

**Rationale:** Cloud runners have no `.venv/`, no local data files, and only see pushed commits. The audit scripts require all three. Cloud Routines are appropriate only for reasoning-level checks (changelog consistency, phase ordering) that do not need Python execution.

### Systemd timers with `Persistent=true`

**Decision:** Use systemd user timers instead of crontab. `Persistent=true` causes missed runs (PC off/suspended) to fire immediately on next boot.

**Why not cron:** cron silently discards missed runs. For a developer laptop that is regularly closed, this means most scheduled audits would never execute.

### Session-end quick run as primary manual trigger

**Decision:** Documented a four-script session-end quick run (cross-lib, deps-verify, task-drift, template-flags) as the primary manual trigger pattern. These four are fast (~seconds each) and cover the most common sources of drift.

### Decisions Made / Rules Solidified

**No hardcoded path fallbacks** — `instructions_file` reads from `bootloader.get_agent_config()` and raises `ValueError` if the key is absent. This applies to any persona-config-driven file path. A hardcoded fallback would violate the no-hardcoded-paths rule and create a silent failure for operators who misconfigure a template.

**`format_error_turn` is a method on `ParseResult`**, not a standalone function. Any handler importing from `agent_tool_parser` should call `parse_result.format_error_turn()`, not import a separate function.

**Tool-call round limit**: 3 rounds max per send. After 3 rounds without a clean (no-tool-call) reply, the last raw reply is used as the final assistant message. This prevents runaway loops on malformed agent responses.

**CSS feedback**: never change existing `.bp-agent-*` background colors even if the intent is "making it match the sidebar." Sidebar background is `#c0c0c0` (Dark Grey). Agent message bubbles are `#f5f5f5` (light) on purpose — contrast with sidebar. Always check the existing value before deciding to change it.

### False Start

- Tried `bootloader.get_blueprint_agent_adapter()` — method is actually `get_agent_adapter()`. Always grep the bootloader for exact method names before writing handler code.
