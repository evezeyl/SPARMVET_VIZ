## Changes Made

### Wave 1 — Deployment hardening (commits `34ef9d3`, `918c927`, `835081f`)

**Export flag consolidation** (`export_bundle_enabled` + `export_graph_enabled` → `export_enabled`):

- All 8 persona templates updated: `export_enabled` is `true` for standard 6 personas; `false` for `demo-vetinst` and `web-demo`.
- `app/handlers/export_handlers.py`, `single_graph_export_handlers.py`, `home_theater.py`: all `is_enabled()` calls updated.
- `docs/workflows/ui_persona.qmd`: flag table updated.
- **Rationale**: the scope toggle in the new export design makes the split redundant; single flag simplifies template maintenance.

**Ghost-save gating for `qa` persona**:

- `app/handlers/audit_stack.py`: added `bootloader=None` parameter; `_write_t3_ghost` now guarded by `bootloader.get_automation_setting("ghost_save", "enabled")`.
- `app/src/server.py`: `bootloader=bootloader` threaded through to `_define_audit_server`.
- **Rationale**: qa has `t3_sandbox_enabled=true` (so the audit handler IS registered) but ghost writes during CI were making Playwright runs non-deterministic.

**`blueprint_enabled` + `test_lab_enabled` flags added**:

- Both were referenced in `server.py` but absent from all templates — always defaulted to `False`, silently disabling Blueprint and Test Lab for all personas.
- Added to all 8 templates with correct per-persona values.
- Added to `PersonaValidator._REQUIRED_FLAGS` and test `_FULL_FEATURES` dict.

**PersonaValidator Rule 6** (T3 companion cascade, fatal error):

- If `t3_sandbox_enabled=True` but any companion (`comparison_mode_enabled`, `audit_report_enabled`, `session_management_enabled`, `export_enabled`) is `False` → startup error.

**Bootloader backward compat**:

- `_load_persona_config` auto-maps old `export_bundle_enabled`/`export_graph_enabled` to `export_enabled` at load time.
- `manifest_selector_visible` mirrored into `features` dict so `bootloader.is_enabled("manifest_selector_visible")` works.
