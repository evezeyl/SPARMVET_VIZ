### Wave 3 — ADR-073: Configurable Sidebar Slot Registry

**Authored and decided. Implementation pending (Phase 31).**

Key decisions:
- **Two independent layers**: slot list (layout, in persona template) vs feature flag (capability, unchanged). A disabled flag silently skips a panel in the slot list.
- **Per-workspace configuration**: `workspaces.home`, `workspaces.blueprint`, `workspaces.gallery`, `workspaces.test_lab` — each with independent `left_sidebar` and `right_sidebar`.
- **`!include` shared configs**: `config/ui/sidebars/` holds reusable panel-list YAML files. Multiple personas sharing the same layout reference the same file.
- **`PANEL_REGISTRY`** in `app/modules/sidebar_registry.py` — headless-safe (Two-Category Law). Each entry: panel type name → renderer ref + gate flag.
- **Visibility control**: `visible: true/false` in template. Auto-hide if `visible` unset and all panels skip.
- **Fixes ADR-053 violation (task 25-O)**: right sidebar structural exclusion moves from persona-name string comparison in `ui.py` → `bootloader.get_sidebar_config("home", "right").visible`.
- **`SidebarValidator`** + `scripts/validate_persona_config.py --all --strict` for CI and pre-deployment gate.

## Wave 6 — Library dependency model clarification (later in session)

**Design decision:** Two-tier library dependency model formalized and propagated.

- `libs/utils/` = **base layer** (stdlib + polars only; importable by any domain lib; must be declared in `pyproject.toml`)
- All other `libs/` = **domain layers** (zero peer-to-peer cross-lib imports; independently reusable)
- `app/` = **orchestration layer** (only place that wires multiple libs together)

**Rationale:** Each domain lib must be usable standalone — different UI (CLI, API, Galaxy) can import only the layers it needs.

**Terminology fix:** "data-agnostic" was ambiguous. Replaced with:
- _Manifest-driven_: no hardcoded domain knowledge (species, gene names); all behavior injected via manifest/config at runtime
- _Domain-agnostic at the import level_: no cross-lib peer imports
