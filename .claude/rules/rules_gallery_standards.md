# Gallery Asset Standards (rules_gallery_standards.md)

**Authority:** Enforced on all static gallery assets in `assets/gallery_data/`.

## 1. The Scientific Triplet (Mandatory Files)

Every gallery bundle directory MUST contain exactly:

- **`data_analysis_recipe.yaml`**: The executable logic: a standard recipe of format 1, checked in the `gallery` profile (D-0039, DEC47; D-0251).
- **`example_data.tsv`**: A representative dataset (tab-separated).
- **`example_meta.md`**: High-density scientific guidance and author metadata.
- **`preview_plot.png`**: The rendered evidence of the visualization.

## 2. Taxonomy Requirements (6-Axis, ADR-063)

The plot entry of the example holds a `taxonomy` mapping with five axes; the sixth, `geom`, is derived from the first `geom_*` or `stat_*` layer and is not typed (D-0034, D-0039, DEC47; built in all bundles, e.g. `assets/gallery_data/bar_simple/data_analysis_recipe.yaml`). The name of the example is the `ui_label` of the plot entry; `info` holds `label`, `description` and `submission_date`:

```yaml
info:
  label: Example Name
  submission_date: 'YYYY-MM-DD'
analysis_groups:
  example:
    ui_label: Example
    plots:
      example_plot:
        ui_label: Example Name
        taxonomy:
          family: Distribution             # 📊  see §2a
          pattern: 1 Numeric, 1 Categorical  # 🔢  see §2b
          difficulty: Intermediate         # 📈  Simple | Intermediate | Advanced
          show: distribution               # 🎯  see §2c
          sample_size: medium+             # 📏  see §2d
        # ⚙️ geom: derived from the first geom_* / stat_* layer
```

**Canonical reference:** `assets/gallery_data/TAXONOMY_CHEATSHEET.md` — single source of truth for all allowed values and icon assignments. Do NOT invent new values; add them to the cheatsheet first if needed.

### §2a — 📊 Family (Purpose)
`Comparison` · `Correlation` · `Distribution` · `Evolution` · `Part-to-Whole` · `Ranking`

### §2b — 🔢 Data Pattern
`1 Numeric` · `1 Numeric, 1 Categorical` · `1 Numeric, 2 Categorical` · `1 Numeric, 2 Categorical (Faceted)` · `2 Numeric` · `2 Numeric, 1 Categorical` · `2 Numeric, 1 Categorical (Faceted)` · `3 Numeric (Matrix)` · `1 Year, 1 Numeric` · `1 Year, 1 Numeric, 1 Categorical`

### §2c — 🎯 What it Shows
`change` · `distribution` · `frequency` · `normality` · `proportion` · `ranking` · `relationship` · `trend` · `uncertainty`

### §2d — 📏 Sample Size
`any` · `individual points` · `medium+` · `large`

### §2e — ⚙️ Primary Geom
The exact plotnine function name (lowercase, underscore). Must be the first `geom_*` or `stat_*` layer in the example. See `TAXONOMY_CHEATSHEET.md` for the full allowed list.

## 3. example_meta.md Standard Format (ADR-061, ADR-063)

All `example_meta.md` files follow a 3-tier structure:

```markdown
## [Example Name]

> 📊 Family · 🔢 Data Pattern · 📈 Difficulty · ⚙️ geom_name · 🎯 show_value · 📏 sample_size_value

### Section Heading
…
```

- `##` = example name (h2) — NOT `# Steps Metadata: …`
- `>` blockquote = 6-field taxonomy tag strip on the line immediately after the h2
- `###` = content section headings (Suitability, Data Schema, Transformation Logic, etc.)
- Icon assignments MUST match the cheatsheet exactly: `📊 🔢 📈 ⚙️ 🎯 📏`

## 4. VizFactory Layer Format

Examples use the VizFactory data analysis recipe format. **Do NOT use `geom:` as a layer key** — use `name:`. Mapping belongs at the global `mapping:` key under the plot, not per-layer.

Correct:
```yaml
analysis_groups:
  example:
    ui_label: Example
    plots:
      my_plot:
        ui_label: My plot      # the plot entry holds the content directly: there is no `spec:` key
        mapping:
          x: column_a
          y: column_b
        layers:
          - name: geom_point
```

Wrong (both errors):
```yaml
analysis_groups:
  example:
    ui_label: Example
    plots:
      my_plot:
        ui_label: My plot
        layers:
          - geom: geom_point        # ← wrong key
            mapping: {x: column_a}  # ← mapping belongs at plot level
```

## 5. The Pivot-Index Integrity Gate

- `gallery_index.json` is the sole source of truth for the UI.
- Direct editing of the index is FORBIDDEN.
- Regenerate via `assets/scripts/refresh_gallery.py` (or `gallery_manager.rebuild_index()`).
- Any bundle missing a required taxonomy field will be excluded from the index.

## 6. Preview PNG Generation

- `preview_plot.png` is generated by `libs/viz_gallery/assets/generate_previews.py`.
- Run after adding or updating any example:
  ```bash
  .venv/bin/python libs/viz_gallery/assets/generate_previews.py [--only name] [--force]
  ```
- The script reads `data_analysis_recipe.yaml` + `example_data.tsv`, renders the first `plot_id` via VizFactory, and writes `preview_plot.png`.
- Do NOT commit a bundle without a valid `preview_plot.png`.
- **Key of the picture (built on branch, D-0400):** the script also writes `preview_plot.picture_key.json` (key of the recipe, the data and the plotnine version) for each picture it keeps or writes; the app compares it at start and names an example whose picture is not current in the Gallery notice. Do not edit this file by hand.
