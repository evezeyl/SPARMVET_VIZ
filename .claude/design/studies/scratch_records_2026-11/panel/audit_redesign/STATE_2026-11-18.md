# The HOME audit redesign (ADR-099): what is decided, what is built, what is not

Digest by the coordinator of a scout's survey, 2026-11-18, about 13:05 by the clock. The scout READ the records and the code of `dev`; it ran nothing.
The slice plan is a separate page: `SLICES_2026-11-18.md`. Nothing is built from this page.

## What the user sees today

- Two choices in the header of HOME. "Plot to show": Result, My view, Compare. "Data to show": Raw, Result, My view (`home_theater.py:995-1048`).
- A filter changes the table on every view, and the plot only on My view (built under ADR-098).
- The Filters panel has Apply, Send to Audit, Add, Reset. "Send to Audit" opens a dialog "Apply to: This plot only / All plots / All except", with a reason.
- The right panel "Pipeline Audit" shows Pending, the active filters, the inherited tier-2 steps, and an Apply button.

## Size, in counts (no hours)

- Code: about 12 files of the app, 8 app features files, 2 libraries, 3 rule files, 1 help page, 2 docs pages, several ADR notes and diagrams.
- Tests: 39 test files hold at least one word of the old model (My view, Compare, the two header choices), about 169 lines. Step 1 and 2 of the task that adapts them are done; the rest is not started.

So the redesign is the piece of work that is allowed, and meant, to change them.
