## S16 where the identity of a column is not clear (recipe 1 and the smallest examples)

### 1. A column built from two columns
- Detailed_summary: `length_ratio`: ['{\'action\': \'polars_with_columns\', \'named_exprs\': {\'length_ratio\': "pl.col(\'hsp_len\').cast(pl.Float64) / pl.col(\'total_len\').cast(pl.Float64)"}}', "{'action': 'modif_filter', 'column': 'length_ratio', 'op': 'ge', 'value': 0.8, 'na': 'remove'}"]
- Summary_phenotype_length_fragmentation: `resistance_points`, `phenotype_count`: ['{\'action\': \'polars_with_columns\', \'named_exprs\': {\'resistance_points\': "pl.when(pl.col(\'value\') == \'Susceptible\').then(pl.lit(0)).when(pl.col(\'value\').cast(pl.String).str.starts_with(\'unknown\')).then(pl.lit(None)).otherwise(pl.lit(1))"}}', '{\'action\': \'polars_group_by\', \'by\': [\'sample_id\', \'ST\'], \'maintain_order\': True, \'named_aggs\': {\'phenotype_count\': "pl.col(\'resistance_points\').sum()"}}']
  The recipe text names the new column (the key of `named_exprs`, or the names in `named_aggs`) but how it relates to the old columns is Python code inside a text string; the engine gives the new column's name and type (`collect_schema`) only.

### 2. An unpivot (wide to long): Quast -> Quast_with_metadata
- step: {'action': 'polars_unpivot', 'on': ['n50', 'total_length', 'largest_contig'], 'variable_name': 'metric', 'value_name': 'value', 'index': ['sample_id', 'source', 'country']}
- at the Quast file, `n50 >= 324189`: 21 of 42 rows (21 samples).
- at Quast_with_metadata (long): the columns `n50`, `total_length`, `largest_contig`, `L50` are GONE (the column list: ['sample_id', 'source', 'country', 'metric', 'value']); the user can only select on `value`/`metric`. `value >= 324189` selects 104 rows (42 samples; the metrics: ['largest_contig', 'n50', 'total_length']); `metric = n50 and value >= 324189` selects 21 rows (21 samples). The dialog has no way to say 'this `value` column is the n50 when metric = n50'.
  The unpivot's arguments (`on: [n50, total_length, largest_contig]`, `variable_name: metric`, `value_name: value`) say it in the recipe; the type of `value` (Float64) comes from the engine. The `L50` column also disappears (not listed in `on` or `index`): the recipe drops it by omission.

### 3. An aggregation
- QA_AMR_per_sample T2: {'action': 'polars_group_by', 'by': ['sample_id', 'country'], 'named_aggs': {'n_amr_genes': "pl.col('gene').count()"}}; columns before ['sample_id', 'country', 'source', 'year', 'gene', 'predicted_phenotype'], after ['sample_id', 'country', 'n_amr_genes']: `gene`, `predicted_phenotype`, `source`, `year` disappear; `sample_id` and `country` stay (they are the group keys); `n_amr_genes` is new (a count).
- QA_aggregated_no_key T2: columns ['country', 'year_label', 'n_samples']; no `sample_id`: a row is a (country, year_label) group of 3 or more samples. `n_samples` counts them.

### 4. The same NAME for two different columns (a search by name would treat them as one field)
- `phenotype`: at Summary_quality it holds ['Susceptible', 'ampicillin, unknown[sitABCD_1_AY598030]', 'gentamicin, spectinomycin, ampicillin, unknown[qacE_1_X68232], unknown[sitABCD_1_AY598030], sulfisoxazole'] (a text of the pipeline summary, 8 values); at ST22_Anchor it is `predicted_phenotype` of ResFinder renamed (step: {'action': 'polars_rename', 'mapping': {'predicted_phenotype': 'phenotype'}, 'strict': True}): values ['ampicillin', 'gentamicin', 'kanamycin']; values in common: ['unknown[sitABCD_1_AY598030]']. The same name, different columns, different tables; the two are not on one lineage (Summary_quality feeds `Summary_phenotype_length_fragmentation`, ResFinder feeds the anchor).
- `value`: String at Summary (['blaTEM-1C', 'sitABCD']), Float64 at Quast_with_metadata ([366418.0, 332629.0]): two columns, one name, two types.
- `ST` / `ST_right`: a join whose two sides both have `ST`: the engine renames the right one `ST_right` (not in the recipe's arguments: Summary_phenotype_length_fragmentation T1:4 `polars_join` added `ST_right`). The columns of that table: ['sample_id', 'ST', 'phenotype_count', 'quality_metric', 'quality_value']. A name search for `ST` finds the left one only.

### 5. Renamed (identity is clear from the recipe but not from the name)
- ST22_Anchor T1:6 {'action': 'polars_rename', 'mapping': {'VF_gene': 'Selected_Virulence_Genes'}}; AR1 T1:4 {'action': 'polars_rename', 'mapping': {'VF_gene': 'selected_virulence_genes', 'VF_protein': 'vf_protein'}} (rename to lower case); the origin of `VF_gene`: VirulenceFinder ["{'action': 'polars_str_splitn', 'columns': ['virulence_raw'], 'by': ': ', 'n': 2, 'target_column': '_split_parts'}", "{'action': 'polars_unnest', 'columns': ['_split_parts']}", "{'action': 'polars_rename', 'mapping': {'field_0': 'VF_gene', 'field_1': 'VF_protein'}}"] (a text column `virulence_raw` is split into two: `VF_gene` and `VF_protein` are built from ONE column; the one column is dropped at the next step).
