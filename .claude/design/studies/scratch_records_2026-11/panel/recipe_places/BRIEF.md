Its save overwrites the component file in place (:1187-1189); its "new recipe" refuses an existing file and its slug regex `^[a-zA-Z_][a-zA-Z0-9_]*$` refuses a hyphen (:2636).

- `write_recipe` does not refuse an existing file; TEST_LAB only offers downloads.
- Sessions: `{user_data}/_sessions/{key}/`; the key is a hash of the recipe's file bytes and of the data, not the id; the id is stored in the record and compared at restore (another id = refused, D-0317). The export file name holds no recipe id.
