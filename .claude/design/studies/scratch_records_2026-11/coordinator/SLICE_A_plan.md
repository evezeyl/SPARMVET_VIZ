## Piece A5, the audit recipe: scope cut from a scout's survey (2026-11-19 evening; READ, nothing run)
Decided and usable now: two recipes, `original_recipe` and `audit_recipe`, the copy only ADDS steps, a step can be removed again from the copy only (D-0102, D-0143); steps at the END of the T1 or T2 list of a table or the T3 list of a plot (D-0146); a step in the copy is a normal step with the marker `id: audit_<8 hex>_<k>` and the reason in `comment` (format spec DEC18; checker profile "audit", code ST08; `STEP_KEYS = action, id, comment`); the audit writes `modif_filter` and `polars_drop` (translator `blueprint_arch.t3_translator.translate_t3_node`, :91-155); "the copy minus its marked audit steps must equal the original, otherwise it blocks" (ADR-105 point 6); keys: the audit parts `[a1] [a2] [a3]` hold the audit operations "without reasons, dates or initials" (ADR-101 point 2); "nothing is ever copied: a stage is either reused or recomputed" and the audit's stored tables live in "a separate audit cache (its own folder, never in the anchors folder)" (`home_audit_steps.md:31`, :229-231); a plot is affected when the content of its T3 differs between the original and the audit run (ADR-101 point 6).
BUILD NOW (no open decision needed), in memory, on the resolved recipe:
1. Pure module in `libs/utils` (`utils.audit_copy`): `marked_steps`, `strip_marked`, `integrity_errors(copy, original)`, `add_step(copy, place, step, step_id, comment)` (place = T1 or T2 of a table, T3 of a plot; end of the list only), `remove_step(copy, step_id)`; id form checked; `check_recipe(profile="audit")` passes on the result.
2. Keys of the copy (`app/modules/cache_keys.py`): the marked steps are taken OUT of the definition parts and enter as the audit parts `a1`/`a2`/`a3` (hash of the operations without `id` and `comment`); an untouched table of the copy has exactly the key of the original's table.
3. A headless run (app layer): builds every table and every plot table of a copy; tables whose key equals the original's are served from the original's stored table (not copied, not rebuilt); changed ones go to the audit's own folder; returns which tables and plots differ from the original (by content).
Tests first: the copy without audit steps gives exactly the original's tables (golden records) and builds nothing; a step at T1, T2, T3 changes only the tables and plots after it; removing the step gives the original back; a reason text change moves no key; integrity fails when an original step was changed.
WAITS (questions for the stop): the FILE of the copy (name, folder, header, whether the author's comments survive in a resolved file); what `k` counts in the id; where date and initials go; the event log (optional or always); whether the checker's audit profile must refuse other actions than filter and drop; replacing the export's tier-2 fork (slice D).
